# Architecture Experiments

This directory contains bounded investigations supporting the source-navigation and assistant-efficiency architecture.

Experiment documents are decision inputs, not implementation specifications. They should record hypotheses, evidence, and consequences without committing the project to a tool or index format.

Keep raw transcripts, generated indexes, caches, and large benchmark outputs outside this repository or in ignored temporary storage. Commit only concise experiment plans and findings.
